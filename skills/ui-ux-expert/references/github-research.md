# GitHub research

Inspected 2026-09-09. This skill is an original, compact synthesis for the user's existing products, not an installation or reproduction of upstream packages. Upstream main branches may change; no upstream scripts were executed or vendored. Review licenses before later copying code or datasets.

## Sources and selected lessons

- [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md): intentional visual direction grounded in the subject, meaningful typography, restrained effects, and critique before delivery. Existing brand requirements take precedence over novelty.
- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md): practical checks for semantics, keyboard focus, forms, motion, content resilience, and navigation. Apply selectively: do not blindly disable autocomplete, virtualize every list, or conceal overflow.
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): links product context to design-system decisions and includes resilient text and interaction guidance. Its catalog and generated recommendations are inspiration, not proof of accessibility, performance, or user outcomes. The catalog/CLI is not installed by this skill.
